# Jetson, NanoPi and I/O expansion / 2026.09.8

First Edition / 2026 is unchanged. This digital snapshot adds **75 listings and 114 reference files**, including **15 physical pinout-image entries**. Eight previously empty records gain references. These counts include partial connector maps and variant records; they are not complete-device approvals.

## Hardware added

- FriendlyELEC NanoPi, NanoPC, compute modules and carrier/I/O boards, including newer M6V2, NEO3 Plus, R28S and T6 Plus documentation. RAM and LTS variants are separated where source images distinguish them. Duo, Duo2, NEO, NEO2, NEO Air, NEO Core, NEO Core2, NEO Plus2 and NanoPC-T1 include physical connector diagrams. Other labeled layouts and schematic tables remain supporting references.
- NVIDIA Jetson Nano, Nano 2GB, Xavier NX, AGX Xavier, Orin Nano, AGX Orin, AGX Thor and TX2 developer kits. Orin Nano J12 and AGX Orin J30 have saved physical header maps. Thor J47 CAN and J511 audio references are signal tables, not Orin-compatible 40-pin maps. Carrier-board revisions and document versions are different identifiers.
- Raspberry Pi Compute Module 4 and 5 IO Board datasheets and visual reference pages; Olimex RK3188-SOM-EVB and AM3352-SOM revision C GPIO maps; RAK13002 WisBlock IO pinout; Antmicro Jetson Orin Baseboard identification render and source design repository.

Manufacturer original files remain unchanged. Rendered PDF pages and the RAK SVG preview retain the original document/vector, source hashes and page scope. Formal board datasheets, hardware manuals, schematics and chip datasheets have separate metadata. Newly checked external schematic links remain online unless explicitly marked saved.

## Catalog-wide documentation inventory

Every listing now states whether its board datasheet, original manufacturer website and visual reference have been recorded. [Full documentation audit](../DOCUMENTATION.md) · [per-listing CSV](../catalog/documentation-coverage.csv) · [pinout audit](../PINOUT_COVERAGE.md).

This is an evidence inventory, not a claim that every missing document has been found. Older unclassified documents do not automatically count as board datasheets. Historical manufacturer-domain links are marked recorded rather than freshly checked. Generic/unidentified hardware cannot be assigned a manufacturer or exact datasheet without evidence. Product photographs, chip package maps and block diagrams do not count as physical board pinouts.

Some legacy NVIDIA downloads require sign-in; these were not bypassed. Public source manuals were used where available. Retrieval failures remain research gaps. Adafruit MCP23017 component documentation is explicitly chip-level and does not substitute for the breakout-board guide.

## Scope and remaining work

The collection has 2,589 board/device records, 501 maker records, 3,354 board reference entries and 1,511 physical pinout-image entries. Many entries still need a physical map, exact PCB revision, classified board datasheet or original manufacturer link. No worldwide completeness, all-pin electrical approval or new power-test results are claimed. The physical book draft and parallel manufacturer working collections are unchanged.
