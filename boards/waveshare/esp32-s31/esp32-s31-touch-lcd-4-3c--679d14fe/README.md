# ESP32-S31-Touch-LCD-4.3C

**Waveshare** · ESP32-S31

Revision: ESP32-S31-WROOM-3-N16R16 version, bare board SKU 36107. PCB revision not identified.

Coverage: Manufacturer diagram available online. Physical H4 terminal layout with pin labels and GPIO48 through GPIO53. Limited to exposed terminal and onboard resources.

[Browse all manufacturers](../../../../BROWSE.md) · [Devices & IoT](../../../../DEVICES.md) · [Open in the browser guide](https://valleytech-black-wire-guide.pages.dev/?board=waveshare-esp32-s31-touch-lcd-4-3c)

The rear-view board drawing maps the 16-position H4 terminal to power, I2C, CAN, RS485 and GPIO48 through GPIO53. The manufacturer also lists H4 and J3 pin numbers. GPIO48 through GPIO53 use native 3.3 V logic. The S3 version has different connections. Exact hardware launch date unknown. Manufacturer documentation names factory firmware dated 2026-10-30.
