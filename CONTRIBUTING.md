# Contribute a board reference

Open an issue with the exact manufacturer, product name, processor and printed PCB revision. Include the official source page and direct image/PDF URL when available, the original creator and explicit license/permission evidence.

We need a diagram of the **physical board**, with readable pin functions. Identify partial diagrams, connector-only maps, chip-package drawings, unknown revisions and unverified sources accurately. Avoid duplicating a board just because its listing name changed. Preserve the original image and credit; do not erase watermarks or redraw ambiguous labels.

For a power-data contribution, include input connector, voltage, current type (supply capacity, average or peak draw), board revision, firmware/workload, peripherals, instrument, date, measurement method and source. Never substitute a typical current reading for a required supply capacity.

For code changes, explain the user-visible issue and test behavior at the affected boundary. Search changes should preserve processor and revision distinctions. Public issues and commits must contain no credentials or private workbench backups.
